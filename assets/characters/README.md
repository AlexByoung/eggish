# 蛋仔角色动画素材

`danzai-spritesheet.png` 是游戏内使用的透明 PNG Sprite Sheet。

- 图片尺寸：`455 × 42`
- 单帧尺寸：`35 × 42`
- 排列方式：单行、从左到右
- 默认朝向：向右；向左移动沿用 Phaser `flipX`
- 色板：深棕 `#562018`、蛋黄 `#FFCC2E`、暖白 `#FFFAF0`、透明
- grounded 帧的鞋底固定在同一基线上
- 每帧直接按 `35 × 42` 逻辑像素重绘，使用连续的 1–2 像素深棕轮廓；不再由高分辨率插画自动缩小
- 身体宽度约为 28–31 像素，并使用放大的眼睛、连续手臂像素簇和相互分离的白鞋，保证实际游戏尺寸下可读

帧范围：

- Idle：`0–2`
- Run：`3–8`
- Jump：`9–10`
- Fall：`11–12`

素材以用户提供的侧面参考图为身份依据，经角色动画源图生成后，再进行透明色键、有限色板、硬边像素化和统一帧对齐处理。游戏继续使用原有 `player` texture key；素材缺失时，代码保留旧蓝色方块作为清晰的加载失败占位图。
